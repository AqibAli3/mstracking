# Mian and Sons Tracking

Project: Logistics tracking webapp using Supabase + React (Vite + Tailwind).
Goal: MVP for customers and admins to track shipments China -> Pakistan.

Structure:
- frontend  : React app (Vite)
- db        : SQL schema files
- docs      : project docs, ER diagrams, deployment notes

How to run locally:
1. Install Node.js LTS
2. cd frontend
3. npm install
4. npm run dev
